# regra_115.gobr

Regras de frequência para dois times, atacado e salmao, sem distinção de perfil de cliente. O time atacado atende todos os clientes a cada 7 dias e o time salmao, a cada 2 dias. Não há bloqueios de agenda.

## Regras

| Segmento | Critério | Frequência | Observação |
|---|---|---|---|
| Time atacado | Clientes de qualquer perfil atendidos pelo time atacado | 7 dias |  |
| Time salmao | Clientes de qualquer perfil atendidos pelo time salmao | 2 dias |  |
